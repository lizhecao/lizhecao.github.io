## 用户明确的方向

- 原图需要的弧形积木可以使用；不能把当前网页只支持方块、长块误当成用户的材料限制。
- 直接采用参考图案，制作可操作的分步教程；保留原造型和所需弧形件等特殊积木。
- 在“大作品”中新增分类，方便按主题选作品。

## 实施与核对要点

- 图片是成品参考；不能将自行推导的步骤说成原作者提供的教程。
- 参考照片和推导的可交互教程应分别标明来源与用途。
- 如制作特殊件教程，渲染、材料名称、凸点位置、可承托区域及逐块说明必须一起支持，避免把弧面当成可随意叠放的平顶。
- 沿用独立 worktree、Hexo skip_render、仅复制应用目录到发布分支的方式；上线后核对文件一致性、旧页面和离线缓存。

## 本轮实现

- 新增 12 个分步造型：弧背小乌龟、蓝色小象、橙壳小蜗牛、尖耳小猫、红色弯颈天鹅、张嘴小鳄鱼、大钳子螃蟹、弧瓣小红花、圆润小苹果、弧顶窗户小屋、双层巴士、弧斗挖掘机。
- 大作品按动物、植物与水果、建筑、载具、人物与机器人、场景分为六类；“新图案”单独展示本轮增加的作品。
- `patterns.js` 保存新增造型数据，普通砖、弧形砖、双高窗框、眼睛印花砖和带轮底盘分别渲染和统计。弧形砖只在平顶区域显示凸点，窗框占两层；镜像时方向提示同步翻转。
- 本轮 139 块新增积木均按凸点网格、层间承托和完成后的整体连通性检查。成品照片有遮挡，教程为重建方案，尚未逐一实物试搭。
- 离线缓存更新到 v6，并把 `patterns.js` 纳入核心文件。保留原有进度键，原有造型 ID 与教程数据不改。

## 复用验证

生成后运行 `node test/verify-block-play-patterns.mjs`、`node test/verify-block-play-page.mjs`、`node test/verify-dca-page.mjs`。
浏览器回归脚本为 `test/verify-block-play-browser.cjs`，需要可用的 Playwright 与 Chromium；可通过 `NODE_PATH` 指定现有 Playwright，`CHROME_PATH` 指定 Chromium 可执行文件。先将 `public/` 在 `127.0.0.1:8765` 启动静态服务，再运行脚本；也可传入线上 `/block-play/` URL。脚本检查全部新增教程、分类、特殊件、镜像提示、进度恢复和离线重载。

## 结构实验室并行核对

现有六项是入门课程选择，混合了连接方法、平衡和造型观察，并不是结构全集。后续可补充转角连接、前后连接、偏心平衡、短挑台、中间支撑和弧形拼接；轮轴、铰链、杠杆和齿轮属于机械功能，需要对应零件。本轮不扩大结构实验室课程数量。
