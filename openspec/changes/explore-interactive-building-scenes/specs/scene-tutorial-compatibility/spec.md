## ADDED Requirements

### Requirement: 成品和搭建使用各自可见集合

系统 MUST 让成品模式显示完整模型再按楼层/家具筛选，搭建模式仅显示当前及之前的零件。相机、楼层、外墙和家具操作 MUST NOT 写入搭建进度；离开成品 MUST 恢复原搭建视图。

#### Scenario: 只搭两步就查看二层成品
- **WHEN** 用户只搭两步后进入成品并选二层
- **THEN** 完整二层与家具显示，不提示尚未搭到；返回后恢复第二步的原楼层、相机和层视图，存储进度不变

### Requirement: 3D 手势不推进步骤

3D 画布 MUST 将旋转、缩放、平移和家具点选与步骤推进分离；前后步骤 MUST 通过明确控件操作。系统 MUST 保留 SVG 教程的既有操作方式。

#### Scenario: 拖动和点按家具
- **WHEN** 用户在普通或全屏 3D 画布拖动旋转、双指缩放、点家具
- **THEN** 当前步骤与存储进度不变，不触发旧画布点击下一步行为

#### Scenario: 按下一步进入另一个楼层
- **WHEN** 用户点击下一步且新零件属于另一层
- **THEN** 系统显示并突出该零件，切换到它所属层；单纯调整相机没有额外步骤变化

### Requirement: 普通界面与全屏一致

系统 MUST 在普通/全屏切换时保留模型、模式、选层、选对象与相机，并避免为缩略图和近景创建多个活动 WebGL 上下文。

#### Scenario: 全屏查看书柜后关闭
- **WHEN** 用户放大书柜、进入全屏、再关闭全屏
- **THEN** 回到同一书柜与相机位置，进度不变；只有一个活动查看器上下文

### Requirement: 触控和替代控件可用

系统 MUST 支持 iPad 单指旋转、双指缩放/平移与画布外滚动，提供视角/缩放/复位按钮和家具列表；主要触控按钮 MUST 至少为 44×44 CSS px，并支持减少动画偏好。

#### Scenario: iPad 横竖屏操作
- **WHEN** 用户在 768×1024、1024×768、1194×834 视口切换楼层和定位家具
- **THEN** 主画布无遮挡或页面横向溢出，控制按钮可触及，并有无需手势的等价操作

### Requirement: 离线资源完整

系统 MUST 随静态网页发布固定版本的 3D 依赖及许可，核心离线缓存覆盖查看器和所有内部依赖；离线准备状态 MUST 不早于必需资源可用。

#### Scenario: 从未打开过 3D 就断网
- **WHEN** 用户在线完成离线准备，尚未进入 3D，随后断网并重载
- **THEN** 可以首次打开完整场景 3D、选择楼层、旋转和查看家具，无引擎 CDN 请求依赖

### Requirement: WebGL 不可用时继续教程

系统 MUST 在 WebGL 2 不支持、初始化失败或上下文丢失时回到可操作的 SVG，保留进度与当前区域。

#### Scenario: 注入上下文丢失
- **WHEN** 当前正在查看二层的 WebGL 上下文丢失
- **THEN** 同一模型和二层由 SVG 继续展示，用户仍可成品预览与前后步骤，保存进度不变

### Requirement: 发布前执行实机性能与既有功能验收

系统 MUST 在已记录的参考 iPad Safari 上，使用 500 块场景持续交互 30 秒验证 P95 帧间隔不高于 33.3ms；未达标 MUST 继续优化或保留 SVG，不得将桌面模拟结果标为实机通过。发布 MUST 保持旧造型、结构故事、语音、两段统计脚本和仅 block-play 目录更新。

#### Scenario: 性能验收记录
- **WHEN** 进入 3D 版本发布验收
- **THEN** 记录实际设备、系统、浏览器、场景规模、画布尺寸、帧统计和资源释放结果，并运行已有页面、模型、成品预览与故事课回归
