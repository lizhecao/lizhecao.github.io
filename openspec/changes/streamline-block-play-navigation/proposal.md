## Why

实际使用中，点击作品后需要滚到长页下方才能搭建；结构实验室、故事与创意任务也混在同一张页面里，返回选作品时容易丢失位置。完整场景的成品查看入口较绕，室内分步又受到墙体和全景尺度遮挡，需要同时理顺导航与当前步骤的查看方式。

## What Changes

- 将长页改为独立视图，以「造型库、完整场景、结构实验室、创意任务」四个 Tab 切换栏目。手机底部导航，iPad/桌面保留等价栏目导航；安装与离线状态放到独立设置入口。
- 作品卡片直接进入该作品的搭建页；实验卡片进入故事实验详情；任务卡片进入任务详情。返回恢复原栏目、筛选、搜索和列表位置，支持浏览器返回/前进与详情链接刷新。
- 使用 GitHub Pages 兼容的 hash 路由实现页面跳转，继续静态部署，不引入后端或前端框架。
- 成品入口直接进入沉浸式查看页：现有六个完整场景默认 3D，提供旋转、缩放、楼层与家具操作；关闭恢复进入前的搭建步骤和视图。成品页移除「查看搭建图」切换，WebGL 故障自动回退到 SVG；普通造型保留静态成品。
- 室内分步自动进入 3D、打开当前楼层与外墙、聚焦正在搭的家具，突出当前新增积木和连接位置。同一家具的连续步骤保持用户调整的角度，提供「回到本步视角」。
- **BREAKING**：图案点击不再推进分步。搭建图/3D 上的点击与拖动只用于查看，前后步骤由明确按钮推进；旧锚点导航改为兼容跳转到对应页面。
- 保留模型 ID、全部 64 个造型、12 个故事实验、现有任务和参考、`block-lab-progress-v4`、语音、离线和两段统计代码；独立 `block-play-preview/` 继续下线。

## Capabilities

### New Capabilities

- `block-play-page-navigation`：栏目 Tab、独立详情视图、直达链接、返回恢复、旧锚点兼容与离线导航。
- `block-play-immersive-viewing`：独立搭建/成品页面、成品默认 3D、明确步骤操作、模式与视图状态隔离及故障回退。
- `block-play-interior-step-guidance`：室内步骤楼层与家具自动定位、新积木/连接提示、稳定相机和可恢复的本步视角。

### Modified Capabilities

无已归档基线规格（当前 `openspec/specs/` 为空）。本提案以新增规格表达本次要求；它调整先前 `explore-interactive-building-scenes` 中默认主动选择 3D、全屏弹窗和 SVG 点击推进的交互约定，不扩展其模型布局或引擎范围，也不把其未完成的真实 iPad/实物验收标为完成。

## Impact

- 产品修改预计涉及 `source/block-play/index.html`、`style.css`、`app.js`、`scene-ui.js`、`scene-viewer.mjs`、`scene-state.mjs`、`pwa.js`、`sw.js`，必要时增加小型本地路由模块；复用现有场景与故事数据。
- 调整依赖长页/弹窗结构的现有浏览器验证，增加导航返回、直接链接刷新、室内可见性、SVG/3D 点按不推进与离线升级回归。性能和真实触摸仍需真实 iPad 证据。
- 实现和发布使用各自独立 worktree，只发布 `block-play/`；不修改博客、DCA、已下线预览路径的退役脚本。
- 本次仅提交 OpenSpec 提案、设计、规格和未勾选任务，不修改产品代码、不部署。实施以这些文档作为后续 `openspec apply` 的输入。
