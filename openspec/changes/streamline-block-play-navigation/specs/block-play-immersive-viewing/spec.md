## ADDED Requirements

### Requirement: 搭建页直接展示当前步骤与明确操作

系统 MUST 在独立搭建页展示当前模型、主图、本步说明、拿取积木提示与前后步骤控件。新作品 MUST 从准备状态进入，旧作品 MUST 从保存步骤继续；主要操作 MUST 不依赖滚到其他栏目。图案点击、缩放、旋转、家具点选和放大查看 MUST NOT 推进步骤，前后与重新开始等明确控件才改变进度。

#### Scenario: 首次开始与图案连续点按
- **WHEN** 新作品处于准备状态，用户点击开始搭后连续点按搭建图或 3D 画布三次
- **THEN** 开始搭进入第 1 步，连续点按保持第 1 步且存储不再变化；点击下一步才进入第 2 步

#### Scenario: 视口中的搭建操作
- **WHEN** 用户在手机或 iPad 横竖屏中打开搭建页
- **THEN** 主图、本步短说明、前后按钮可达且不被底部导航遮挡，主要按钮至少 44×44 CSS px，长材料说明在当前页展开

### Requirement: 完整场景成品直接进入三维页面

现有六个完整场景 MUST 在点击成品入口后直接显示沉浸式 3D 页面，不要求先滚动、点击搭建图或再次选择 3D。该页面 MUST 提供楼层、旋转/缩放、俯视、复位、家具操作和关闭，正常加载时 MUST 不展示「查看搭建图」切换。普通造型 MUST 继续显示静态完整成品。

#### Scenario: 第两步查看完整二层
- **WHEN** 用户仅搭两步，点击完整场景成品入口并选择二层
- **THEN** 直接显示完整二层三维和室内家具，不提示尚未搭到，保存步骤仍为 2

#### Scenario: 普通造型查看成品
- **WHEN** 用户打开双层巴士等普通造型的成品页
- **THEN** 展示完整静态模型且关闭可返回原搭建步骤，不试图创建不支持的三维场景

### Requirement: 关闭成品恢复原搭建状态

成品和搭建 MUST 保持各自的选层、外墙、家具关注和相机状态；关闭成品或浏览器返回 MUST 恢复进入前的搭建状态。打开成品、关闭、栏目切换与路由恢复 MUST NOT 写入或迁移 `block-lab-progress-v4`。

#### Scenario: 旋转二层成品后关闭
- **WHEN** 用户从一层某家具搭建步骤进入成品，切到二层并旋转缩放后关闭
- **THEN** 恢复原模型、步骤、一层、家具和搭建视角，当前步骤及存储内容保持不变

### Requirement: 单查看器与故障回退

页面导航 MUST 避免多个活动 WebGL 上下文，离开三维页面后 MUST 停止渲染或释放资源。WebGL 不支持、初始化失败或上下文丢失时 MUST 在同一路由回到可操作 SVG，保留模型、模式、当前区域与进度。

#### Scenario: 反复进入成品和目录
- **WHEN** 用户连续五次从目录进入搭建、成品再返回目录
- **THEN** 三维页面最多一个活动查看器，目录无后台渲染循环，进度保持且再次进入没有重复画布

#### Scenario: 二层成品失去 WebGL
- **WHEN** 二层成品发生上下文丢失或设备无法创建 WebGL
- **THEN** 当前成品路由显示二层 SVG，选层与关闭可用，图案点按不推进且搭建进度保留

### Requirement: 旧资源与正式部署兼容

系统 MUST 保留全部模型 ID、旧/新版独立进度、语音和两段统计脚本；新增核心资源 MUST 纳入离线缓存，并同步更新 SW/PWA 版本。发布 MUST 仅更新正式 `block-play/`，独立预览退役脚本、博客与 DCA MUST 保持原样。

#### Scenario: 从 v18 安装升级
- **WHEN** 用户带着 v18 离线缓存、旧模型第 80 步和独立新模型进度升级本版本
- **THEN** 正式缓存按作用域升级，两套进度不变，断网刷新可进入新页面和首次三维，统计代码各保留一次，preview 保持下线
