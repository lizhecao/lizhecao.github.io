## ADDED Requirements

### Requirement: 四个栏目使用互斥页面与 Tab 导航

系统 MUST 提供造型库、完整场景、结构实验室、创意任务四个栏目 Tab；任一时刻 MUST 只显示当前页面，切栏目 MUST NOT 滚到同一长页的锚点。安装与离线说明 MUST 从设置入口进入独立页面。

#### Scenario: 从造型库切换到结构实验室
- **WHEN** 用户点击结构实验室 Tab
- **THEN** 页面显示实验目录且该 Tab 选中，造型库/搭建/任务内容隐藏，无需经过其他栏目下拉寻找实验

#### Scenario: 手机与 iPad 切栏目
- **WHEN** 用户在 390×844、768×1024、1024×768 或 1194×834 视口操作栏目导航
- **THEN** 四个栏目均可达，触控目标至少 44×44 CSS px，安全区不遮挡内容且不存在横向溢出

### Requirement: 卡片一次点击进入独立详情

作品卡片 MUST 直接打开相应模型搭建页；实验和创意任务卡片 MUST 打开对应详情页，MUST NOT 依赖长页滚动。结构实验目录 MUST 保留现有 12 个故事实验的入口，作品目录 MUST 保留原有 64 个造型及新增 12 个原创造型（共 76 个）和现有分类/搜索。

#### Scenario: 选择一个已搭作品
- **WHEN** 用户点击已有第 80 步进度的作品卡片
- **THEN** 直接显示该模型搭建页及第 80 步，无需下拉到搭建区，不重置存储进度

#### Scenario: 从故事去实践
- **WHEN** 用户在实验详情看到某个故事任务并点击关联作品练习
- **THEN** 打开该作品搭建页，返回实验恢复原故事任务和对照状态

#### Scenario: 搭好后的作品创作
- **WHEN** 用户完成模型后点击自己改一改
- **THEN** 进入该模型的独立创作页并显示现有三个挑战，返回恢复已完成模型，不滚到全站创作区域

### Requirement: 返回恢复来源与列表上下文

系统 MUST 支持页面返回与浏览器返回/前进，并恢复当前会话来源页的筛选、搜索、加载数量、滚动位置以及实验任务状态。步骤按钮 MUST NOT 为每一步增加路由历史，返回 MUST NOT 意外退一搭建步骤。

#### Scenario: 搜索后搭建再返回
- **WHEN** 用户在大作品分类中搜索、加载更多并打开作品，推进若干步后返回
- **THEN** 返回原筛选、搜索、加载范围和列表位置，搭建进度保留；前进可再次进入该作品

#### Scenario: 在详情间往返
- **WHEN** 用户从搭建页进入关联实验，又从实验返回
- **THEN** 回到原模型及步骤，实验内容没有混入搭建页，来源关系不被栏目默认入口覆盖

### Requirement: Hash 路由支持直达刷新与旧入口

系统 MUST 使用静态 GitHub Pages 可访问的路由，支持目录、模型、实验、任务和设置直达；刷新 MUST 按路由打开正确页面并读取原进度。旧锚点 MUST 映射到对应新页面；未知路由或 ID MUST 提示并回到合适目录，不写入或清零进度。

#### Scenario: 刷新成品直达链接
- **WHEN** 用户打开并刷新 `/block-play/#/preview/scene-courtyard-home-v2`
- **THEN** 显示该模型成品页；没有来源时关闭进入同模型搭建页，已保存步骤保持不变

#### Scenario: 旧实验锚点与失效模型
- **WHEN** 用户打开 `#learning` 或 `#/build/unknown-model`
- **THEN** 前者进入实验目录，后者提示并返回作品目录，均不改已有搭建进度

### Requirement: 隐藏页面隔离与离线导航

非当前页面 MUST 从布局、键盘和读屏访问中隐藏；进入页面 MUST 更新标题并移动焦点到页面标题。离线准备完成后，栏目和详情路由 MUST 能首次进入并刷新，不依赖远程路由服务或 CDN。

#### Scenario: 键盘切换到任务详情
- **WHEN** 用户打开任务详情并使用键盘或读屏导航
- **THEN** 焦点和标题对应当前任务，隐藏的其他栏目控件不进入导航顺序

#### Scenario: 首次离线实验与模型直达
- **WHEN** 用户完成离线准备后断网，打开未进入过的实验或完整场景详情并刷新
- **THEN** 显示正确内容和已有进度，导航与返回可用，无服务端 404 或资源缺失
